# مقياس زمن الرجع الحسي الإلكتروني لذوي الإعاقات العقلية

إعداد: أ.د. منى كمال أمين عبد العاطي  
أستاذ ورئيس قسم الإعاقة العقلية، كلية علوم ذوي الاحتياجات الخاصة، جامعة بني سويف – مصر

تطبيق ويب عربي لإدارة وتطبيق اختبارات زمن الرجع الحسي البصري والسمعي، وحفظ النتائج الفردية والمجمعة، وتصديرها إلى ملفات Excel حقيقية.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة، أو تشغيل خادم محلي:

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية.

## البناء

```bash
npm run build
```

ينشئ الأمر مجلد `dist` الجاهز للاستضافة.

## الرفع على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع ملفات المشروع الموجودة في هذه الحزمة إلى الفرع `main`.
3. من `Settings` ثم `Pages` اختر `Deploy from a branch`.
4. اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.

## إعداد Firebase

التطبيق يحتوي على إعداد مشروع Firebase داخل `app.js`. لتشغيل المزامنة السحابية:

1. أنشئ قاعدة Firestore ومساحة Storage للمشروع إن لم تكونا موجودتين.
2. فعّل تسجيل الدخول المجهول من Firebase Authentication ← Sign-in method ← Anonymous.
3. انشر ملفي القواعد المرفقين: `firestore.rules` و`storage.rules`.

لا يشترط التطبيق تسجيل الدخول. قاعدة النتائج عامة كما هو مطلوب: أي زائر يستطيع حفظ النتائج ورؤية جميع البيانات. لذلك **نشر ملف القواعد خطوة إلزامية**، ورفع الملفات إلى GitHub وحده لا ينشر قواعد Firebase.

مثال باستخدام Firebase CLI بعد ربط المجلد بمشروع Firebase عبر `firebase use --add`:

```bash
firebase deploy --only firestore:rules,storage
```

## ملاحظات البيانات

- اسم الطالب وعمره وجنسه وفئته إلزامية، ونسبة الذكاء وبيانات المختص اختيارية.
- المحاولات التدريبية غير محتسبة في النتائج الرسمية.
- ينشئ النظام معرفًا داخليًا مخفيًا لكل بطارية اختبارات، ولا يستخدم الاسم كمفتاح للسجل.
- يحفظ التطبيق كل نتيجة مباشرة في Firebase، ويحتفظ بنسخة محلية احتياطية في المتصفح.
- بعد انتهاء كل اختبار تظهر رسالة تؤكد نجاح الحفظ السحابي، أو تنبيه واضح إذا لم يؤكد Firebase الحفظ.
- قاعدة النتائج مشتركة: أي اختبار يُجرى على جهاز متصل يظهر في النتائج على بقية الأجهزة.
- يمكن تصدير الجلسة الحالية، ونتائج الطالب، وجميع النتائج إلى Excel.
- يحتوي تصدير التقرير الجماعي على ملخص عربي، وإجماليات المحاولات، ووقت كل محاولة رسمية لكل طالب.
- يضيف التصدير ورقتين منظمتين باسم `زمن الرجع البصري` و`زمن الرجع السمعي`: يظهر كل طالب في صف واحد، وتظهر محاولات البسيط والتمييزي والاختياري أفقيًا، ثم أعداد الصحيحة والخاطئة والمبكرة والمتأخرة والفائتة قبل مجموع كل مستوى.
- يوجد قسم مستقل باسم «إعدادات الاستجابة» يحدد حدود الاستجابة الصحيحة والمتأخرة والفائتة لكل فئة. الاستجابة الأقل من 200 مللي ثانية مبكرة دائمًا ولا يمكن تعديل حدها.
- الحد الأعلى لنطاق الاستجابة الفائتة هو نهاية انتظار الاستجابة ومدة بقاء/استمرار المثير، ويتغير تلقائيًا حسب فئة الطالب.
- تُحسب المجاميع والمتوسطات والانحرافات المعيارية من أزمنة الاستجابات الصحيحة فقط. وتُستبعد الاستجابات الخاطئة والمبكرة والمتأخرة والفائتة. الاستجابة الفائتة تحفظ بلا زمن استجابة، ولا تُستبعد أسرع أو أبطأ استجابة تلقائيًا.
- القيم العامة الافتراضية: 4 محاولات تدريبية، و20 محاولة رسمية، وانتظار عشوائي للمثير من 500 إلى 1500 مللي ثانية. ترتيب المثيرات عشوائي دائمًا.
- اسم الطالب وعمره وجنسه وفئته حقول إلزامية عند بدء الجلسة، وتظل نسبة الذكاء اختيارية.
- يظهر مؤشر تركيز (+) ثابت في منتصف شاشة الاختبار، وتحتوي أوراق Excel البصرية والسمعية على الفئة ومجاميع أنواع الاستجابة الخمسة.

## الأصوات الحقيقية ورفع WAV

- حُذفت الأصوات القديمة والمصطنعة نهائيًا، وأصبحت القائمة الجاهزة تضم الملفات التي قدمها صاحب المشروع: كلب، قطة، عصفور، بقرة، حمار، وماعز.
- الملفات الستة موجودة داخل `assets/audio` وتعمل محليًا ومن النسخة المنشورة دون الاعتماد على مواقع أصوات خارجية.
- يتضمن مشغل الصوت مسارًا احتياطيًا عبر عنصر الصوت في المتصفح إذا منع المتصفح جلب WAV عند فتح `index.html` مباشرة. وعند النشر يجب رفع مجلد `assets` كاملًا مع بقية ملفات المشروع.
- يدعم الرفع ملفات WAV وMP3 وOGG وM4A وWebM حتى 10 ميجابايت. صيغة WAV مدعومة، والأضمن استخدام PCM غير مضغوط 16-bit بمعدل 44.1 أو 48 kHz.
- كان سبب فشل الرفع السابق تعارض ثلاثة حدود في الواجهة والكود (500KB و5MB و768KB)، إضافة إلى احتمال بدء الرفع قبل اكتمال تسجيل الدخول المجهول أو عدم نشر قواعد Storage. تم توحيد الحد إلى 10MB، وانتظار المصادقة، وإضافة رسائل خطأ تحدد السبب.
- توجد بيانات الملفات الصوتية المرفقة في ملف `SOUND_SOURCES.md`.

## الملفات الرئيسية

- `index.html`: واجهة التطبيق.
- `styles.css`: التصميم المتجاوب والطباعة.
- `app.js`: إدارة الاختبارات والبيانات والتقارير والتصدير.
- `audio.js`: تشغيل المثيرات السمعية.
- `assets/audio`: ملفات الأصوات الحقيقية المرفقة.
- `SOUND_SOURCES.md`: بيانات ملفات الأصوات الحقيقية.
- `firestore.rules`: قواعد حماية قاعدة البيانات.
- `storage.rules`: قواعد حماية الملفات.
- `build.mjs`: إنشاء نسخة الإنتاج داخل `dist`.

## تنبيه علمي

المقياس أداة إلكترونية لجمع زمن الاستجابة والنتائج الخام. لا ينبغي وصفه بأنه مقنن أو استخدام درجات معيارية قبل إتمام دراسات الصدق والثبات والمعايير على الفئة المستهدفة.
